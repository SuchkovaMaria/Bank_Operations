# Курсовая работа №1.Приложение для анализа банковских операций.

## Описание:

Данный проект разрабатывался в рамках курсовой работы и содержит следующий функционал:
1. Открытие и чтение файла;
2. Сортировка операций по доходам (с подсчетом суммы по категориям и выводом популярных);
3. Сортировка операций по доходам (с подсчетом суммы по категориям);
3. Вывод данных в заданом диапазоне;
4. Поиск операций по описанию и/или категории;
5. Вывод операций по категории за 3 месяца (отчет);
6. Декоратор для записи отчета в файл .xlsx.
7. Вывод курса валют
8. Вывод стоимости акций

## Установка:

1. Клонируйте репозиторий
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Bank_Operations)
2. Установите зависимости

1. Откройте проект.
2. Введите данные, запрашиваемые функциями.
